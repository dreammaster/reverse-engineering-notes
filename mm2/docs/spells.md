# Spells

`SPELLS.DAT` (192 bytes, loaded to `DGROUP:7D60` = `g_spells`) has 96 x 2-byte entries.  **Index 0-47 =
the Sorcerer list, 48-95 = the Cleric list** (`cast_spell_menu` `1554A` adds 30h for classes other than
Archer(2)/Sorcerer(4); so Paladin and Cleric use the cleric list).  The spells of a division are grouped
by spell level 1-9 with 7,7,6,6,5,5,4,4,4 spells (`DGROUP:5054` first index, `505E` counts).
Names are **not in the executable**: they come from the manual (`Manual.pdf`); the joined table below
was generated by `tools/gen_spell_table.py` and the usage/type bits agree with the manual for all 96.

Entry (`b0`, `b1`):

| Bits | Meaning |
|---|---|
| b0 bits 6-7 | usage: 0 anytime, 1 combat only, 2 non-combat only (`spell_usable_here` `1545A`) |
| b0 bits 0-5 | gem cost (`154EE`; values above 50 are capped to 100) |
| b1 bits 0-3 | spell point cost; 0 = special formula (`spell_calc_cost` `13AEA`: 8 or 10 + monster count...) |
| b1 bits 4-5 | multiplier: cost per level of the caster (`level * mult`) |
| b1 bit 7 | extra location restriction (outdoors/indoors/dungeon, see the manual's TYPE text) `154AE` |

Casting: `cast_spell_menu` asks for the spell level (1..character's spell level) then the number in that
level, checks usage/location/gems/SP, and returns the index.  Non-combat use dispatches through the
96-entry jump table in `2CAST1:cast_noncombat_spell` (`1D0C2`); combat spells through the table in
`2CAST2:cast_spell_dispatch` (`1CF2C`; its table is indexed from spell 2).  The per-spell
implementations are named `spell_nc_<Name>` / `spell_cb_<Name>` in the IDA databases.  Pure damage
spells (Energy Blast, Flame Arrow, Fire Ball, Lightning Bolt, ...) are resolved by the combat overlay
(`combat_party_spell_hits`, damage values from the tables at `DGROUP:102A..1032`).

## Combat spell parameters (read from `2CAST2` handlers)

Every combat handler prepares `word_27816` (damage) and/or `byte_27812/27813` (status kind) and calls
`2COMBAT:combat_party_spell_hits(count, first_target, element)` (`18696`).  `count` = number of monsters hit
(10 = the whole group, clamped to the monsters present; 1 = the chosen one), `element` is the damage/resistance class
(1 fire, 2 electricity, 3 cold, 4 acid/poison, 6 mental/magic, 0 = none/special) used for the monster's resistance tests.
Damage helper `sub_1A82C(dice, bonus)` = **sum over the caster's level of `rand(1, dice) + bonus`** (`dice = 0` = just
`bonus` per level).

Status spells (`byte_27812`): 1 silence, 2 weaken, 3 frighten (Apparition), 4 sleep, 5 hold (Web, Immobilize, Paralyze),
6 mindless (Feeble Mind), 7 encasement (Air/Water/Earth/Fire Encasement), 8 Fingers of Death, 9 Disintegration.  Sleep,
Web and Silence use `sub_1A7EA` for the number of monsters affected (`level + 4` below level 7, else up to 10 depending on the
group size).  Party buffs (Shield, Power Shield, Bless, Invisibility, Heroism: +6 levels, ...) set the status bytes
`1DC33..1DC36` described in save-format.md.  Monster resistance: `byte_27681` (magic resistance %) is rolled first
(`rand(caster level, 90) < n` resists), then the flag bits of the record.  Damage in `combat_party_spell_hits` is halved when
the monster resists ("resisted and").
