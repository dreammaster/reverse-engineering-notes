# Might and Magic — reverse-engineering notes

Notes, exports of IDA databases and tooling for reverse engineering the DOS *Might and
Magic* games, with the aim of adding engines to ScummVM.  Already in ScummVM (and so
**not** tracked here): Might and Magic I (`mm1/`, a local reference copy of that
disassembly, git-ignored) and the Xeen games (Might and Magic 4 & 5).

## Layout

| Path | What |
|---|---|
| `ida_scripts/` | Shared headless-IDA tooling (`run_ida_script.ps1`, `batch_run_and_export.py`) — see [docs/ida-workflow.md](docs/ida-workflow.md) |
| `docs/` | Notes that apply to the whole folder (workflow, conventions, cross-game findings) |
| `mm1/` | Local-only copy of the MM1 disassembly, for comparison. Excluded from git |
| `mm2/` | Might and Magic II: Gates to Another World — see [mm2/docs/overview.md](mm2/docs/overview.md) |

Each game gets its own subfolder with the same shape:

```
<game>/
  <game>.idb  .asm  .idc   main database and its exports (idb is git-ignored)
  docs/                    per-game notes (overview.md = status + how the databases are organised)
  ida_scripts/             game-specific IDA scripts (fixes, renames, struct application)
  tools/                   plain-python helpers that work on the game's files
```

Only `.asm`/`.idc` exports, scripts and docs are committed; `*.idb` and IDA's `id0/1/2, nam, til`
temporaries are ignored.  The exports are regenerated by the scripts after every round of
changes, and the result is committed and pushed.
