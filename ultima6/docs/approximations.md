# Approximations, guesses and borrowed rules

Everything in the stand-alone engine that is **not** a faithful port of `GAME.EXE` / `U.EXE`. The final phase of the project is to replace each entry with the original's
exact behaviour (or, where that cannot be done, to hand the details over for further analysis). Keep this file current: add an entry whenever something is approximated,
and delete it (with the commit that fixes it) when the exact version is in. Places in the code are also tagged with the comment `APPROX(n)` where practical
(`grep -rn "APPROX(" src`).

See also [nuvie_differences.md](nuvie_differences.md): where Nuvie and the original disagree, the original is followed and the difference is logged there.

Legend — **Source**: *own* = invented by me, *Nuvie* = taken from Nuvie's reimplementation (which may itself differ from the original), *partial* = original read but incomplete.
**Original** = routine(s) in the IDA databases (`ultima6/u6/u6_game.asm`, `u6_u.asm`, `u6_end.asm`) to analyse. Addresses are linear offsets as in the docs.

### The original's turn structure (ported: moves, costs and the scheduler loop; the actors' AI is not)

After every command (not after `ctrl-Q`) `command_loop` (145FD) calls **`sub_2AB7A`**, the real per-turn actor scheduler: it first runs `sub_2A8DA`, `sub_2A4B6`
and `sub_2A3BA` (the schedule-walkers, 0x81 worktype handling), then loops: for every actor 1.. with a body, a worktype other than 0, not paralysed
(actor status 2), not asleep unless worktype 0x80, not dead (0x10), with moves left (`ds:8D4A`, `moves[]` = objlist +0x14F1) > 0, on the party's level
and not carried, it works out whether it is inside the 40 x 40 window around the party (`player_x/y - 16 & 0x3F8`) and either walks it
(`sub_2868C`, `sub_27FE6`) or resets its moves; the actor with the greatest `moves / dex` ratio acts next, and every action subtracts moves (`sub_26CC4`);
`sub_13305(minutes)` (time, timers, hazards) is called from `sub_2AB7A`'s caller chain with 1 minute for a normal turn, 0x3C for `conv_execute_command` sleep,
0xA from `sub_275BD`/`cmd_rest` loops (`cmd_rest` 3A706 passes 10), 5 from `show_hull_strength`, etc. (callers: `_main`, `command_loop` case 0xD7, `sub_149D7`,
`sub_18668`, `climb_ladder`, `sub_1890C`, `sub_25495` (spells), `sub_275BD` (party movement), `sub_298D0`, `sub_2AB7A`, `use_torch`, `use_fan`).
**Now ported** in `Game::runTurns`: moves per minute = dexterity (carried over), candidate rules, first-with-full-moves / best-ratio choice, refill + one minute when nobody can act, step cost `5 + high nibbles of the terrain and object TILEFLAG bytes on the square left` (`sub_28F67`, `World::moveCost`), halved on a horse (`sub_26CC4`, `World::spendMoves`), Get 3, Attack 10, Cast circle*3+10, Pass = 0 moves. What is still ours: what a chosen actor *does* (`sub_29BDA`, `sub_2A8DA`, `sub_27FE6`, `sub_26D19` - the worktype handlers), actors outside the window with schedule-walking worktypes 0x83-0x86, the minute-by-minute companions' blows, and the commands whose cost I have not read (Use, Talk, Drop, Move ...).
